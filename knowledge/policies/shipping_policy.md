# 配送与运费政策

## 一、配送范围

本商城目前已覆盖全国 31 个省、自治区和直辖市（港澳台地区暂不支持配送）。部分偏远地区（新疆、西藏、青海、内蒙古）的配送时效可能有所延长。

## 二、配送方式

商城合作的物流公司包括顺丰速运、中通快递、圆通快递、韵达快递和 EMS 邮政特快专递。系统会根据收货地址和商品类型自动匹配最优物流公司。

## 三、运费标准

| 订单金额     | 运费   |
| ------------ | ------ |
| 满 99 元     | 包邮   |
| 50-99 元     | 8 元   |
| 不满 50 元   | 12 元  |

特殊说明：秒杀商品无论金额大小均享受包邮服务。大件商品（重量超过 20kg）运费按实际物流报价收取，客服会与您沟通确认。

## 四、配送时效

| 城市级别 | 配送时间       |
| -------- | -------------- |
| 一线城市 | 1-2 个工作日   |
| 二三线城市 | 2-3 个工作日 |
| 四五线城市 | 3-5 个工作日 |
| 偏远地区 | 5-7 个工作日   |

订单在当日 16:00 前支付成功的，当天发货；16:00 之后的订单次日发货。节假日顺延。

## 五、物流跟踪

发货后系统会自动将物流单号推送给用户，可在"我的订单"中查看物流详情。如超过预计配送时效仍未收到商品，可联系在线客服查询和处理。

## 六、签收与丢失处理

请用户在收到包裹时当面验货。如发现包裹破损、数量不符，请拒收并联系客服。如包裹在运输途中丢失，商城将全额退款并补偿 10 元优惠券。
